## Platform
web
## Stack
Next.js, explicitly selected by the user. Static export suitable for hosting; interactions and progress are browser-local.
## Users
Thai vocational diploma students with little networking background. Primary operator is the teacher presenting at the front of the classroom.
## Product Purpose
Teach week one networking and OSI using the approved OSI material (original chapters 03–10). Preserve its explanations rather than replacing them with summaries alone.
## Operating Context
Two class meetings of two and three periods. Teacher-led presentation, with student review possible on smaller screens.
## Capabilities and Constraints
Full Thai lesson reading, step-controlled OSI visualizations and selectable OSI layers. No real network tests: any terminal activity must clearly say simulation. No accounts or claimed server-side assessment. Private hosting by default.

## Product Principles
Preserve complete explanations. Make layers and packet flow visible. Let the teacher control pace. Keep examples distinct from actual device values. Use Thai that beginners can understand.


## IPv4 course extension
14 Thai lessons cover binary conversion, masks, address ranges, AND, block sizes, cross-octet calculations, same-subnet checks, host sizing, FLSM, VLSM, wildcard masks, summarization, references and practice. Teacher-paced animations offer explicit play/pause/previous/next/reset controls; reduced-motion CSS removes transitions. Arithmetic uses unsigned-safe Number operations and treats /31 as point-to-point and /32 as a single address. Host-demand sizing deliberately uses ordinary LAN rules, including gateway demand. The IPv4 course retains the existing OSI content and visual system. Browser QA is pending due to preview socket restrictions; build and arithmetic tests pass.


## Unit navigation update
The default landing view is a unit directory. Unit 1 owns OSI reading/exploration/packet-flow activities, and unit 2 owns the IPv4 course. Each has its own sidebar, unit identity and accent. Hash URLs preserve direct lesson access and browser navigation. No new hosting or publication configuration is introduced.
